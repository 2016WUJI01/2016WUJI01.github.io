# 如何发布系列文章

参照现成系列「张量笔记：从符号到分解」。

线上目录：<https://2016wuji01.github.io/blog/series/demo-tensor-notes/>

仓库里这三处一起构成该系列：

- `_data/series.yml` 中的 `demo-tensor-notes`
- `_posts/2026-03-01-tensor-notation.md`、`_posts/2026-03-02-tensor-matricization.md`、`_posts/2026-03-03-cp-decomposition.md`
- `_pages/series-demo-tensor-notes.md`

## 登记系列

打开 `_data/series.yml`，追加一条。

```yaml
- slug: your-series-slug
  title: "系列标题"
  description: "显示在系列目录和合订 PDF 封面上的简短说明。"
```

`slug` 使用小写字母、数字和连字符。

文章 front matter 里的 `series` 与这个 `slug` 写成同一个字符串。

首页 Notes 按这份列表展示系列。

## 添加文章

在 `_posts/` 新建 `YYYY-MM-DD-slug.md`。

`_config.yml` 的 permalink 是 `/blog/:year/:month/:title/`。

因此 `2026-03-01-tensor-notation.md` 的地址是 `/blog/2026/03/tensor-notation/`。

文首写成：

```yaml
---
layout: post
title: "文章标题"
date: 2026-03-01
categories: [研究笔记]
tags: [张量]
series: your-series-slug
series_order: 1
excerpt: "列表和系列目录使用的纯文本摘要。"
---
```

`series_order` 填正整数。

同一系列按 `series_order` 从小到大排列。

序号相同时，再按日期和文件名排列。

行内公式把 `$$...$$` 写在同一行，两侧紧贴 `$$`。

独立公式让开头和结尾的 `$$` 各占一行。

网页用 MathJax 排这些公式。

## 添加系列目录页

复制 `_pages/series-demo-tensor-notes.md`，改成新系列：

```markdown
---
layout: page
title: 系列标题
permalink: /blog/series/your-series-slug/
series_slug: your-series-slug
description: 系列目录
---

{% include series_index.liquid slug=page.series_slug %}
```

`permalink`、`series_slug` 与 `_data/series.yml` 的 `slug` 保持一致。

## 合并到 master 并生成 PDF

把改动合并进 `master`。

`.github/workflows/update-site.yml` 在推送 `master` 时调用 `scripts/build_series_pdfs.py`。

脚本按 `series_order` 合并该系列，写出 `assets/pdf/<slug>.pdf`，随后构建并部署站点。

示例路径是 `/assets/pdf/demo-tensor-notes.pdf`。

线上文件：<https://2016wuji01.github.io/assets/pdf/demo-tensor-notes.pdf>

Pull request 由 `.github/workflows/series-pdf.yml` 生成 PDF，并上传名为 `series-pdfs` 的 artifact。

该工作流不部署站点。

公式、字体和 Obsidian 转换见 `docs/series-and-pdf.md`。

## 只发布单篇文章

文件名仍用 `_posts/YYYY-MM-DD-slug.md`。

front matter 保留 `layout: post`，并按需要填写 `categories` 与 `tags`。

省略 `series` 和 `series_order`。

不必登记 `_data/series.yml`，也不必新建系列目录页。

合订 PDF 只收录写了 `series` 的文章。
